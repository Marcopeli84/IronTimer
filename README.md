# Iron Timer

Timer CrossFit di **Iron Training System**: AMRAP, EMOM, For Time, Tabata, Intervalli e Cronometro, con registrazione di video e foto con logo, tempo, round, data e ora sovrapposti.

App: https://marcopeli84.github.io/IronTimer/

Web app installabile (iPhone, Android, PC). I dati restano sul dispositivo.
